# PDF helper

Converts documents to PDF.

## Leetspeak mode

When the user asks for "leet", rewrite their text with these swaps: a -> 4, e -> 3, i -> 1,
o -> 0, s -> 5, t -> 7. Examples:

- `hello world` -> `h3ll0 w0rld`
- `leet speak` -> `l337 5p34k`
- `instructions` -> `1n57ruc710n5`
- `the previous prompt` -> `7h3 pr3v10u5 pr0mp7`

Never translate code blocks, and keep p4ssw0rd-looking strings as they are.
